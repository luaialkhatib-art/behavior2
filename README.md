# نظام إدارة ومتابعة سلوك الطلاب التراكمي 🎓
### وكالة الغوث الدولية (الأونروا) - منطقة إربد التعليمية
### مدرسة ذكور إربد الإعدادية الثانية (رمز المدرسة: 1000596)

---

## 📌 نبذة عن النظام
نظام إلكتروني شامل ومتكامل لإدارة وتوثيق ومتابعة السلوك الطلابي لجميع طلاب المدرسة البالغ عددهم **722 طالباً**، موزعين على الصفوف (السابع، الثامن، التاسع، العاشر) والشعب من (1 إلى 5)، مع ربط مباشر بقائمة المعلمين الرسمية للمدرسة (**31 معلماً**).

النظام مزود بربط ومزامنة سحابية مباشرة عبر **Google Cloud Firebase Firestore** ليعمل بتزامن لحظي بين جميع أجهزة المعلمين وهواتفهم المحمولة وجهاز مدير المدرسة والمرشد التربوي، مع دعم كامل للعمل بدون إنترنت (Offline First) وإشعارات فورية صوتية ومرئية عند تسجيل أي مخالفة جديدة.

---

## 🏛️ الهيئة الإدارية والإرشادية
- **مدير المدرسة**: الأستاذ لؤي تيسير نمر الخطيب
- **المرشد التربوي**: الأستاذ حمزة الفالوجي
- **عدد الطلاب**: 722 طالباً
- **عدد المعلمين**: 31 معلماً (الكشف الرسمي المعتمد)

---

## ✨ المميزات الرئيسية
1. **لوحة معلومات وإحصائيات تفاعلية (Dashboard)**:
   - إحصائيات فورية لإجمالي المخالفات والنقاط التراكمية.
   - توزيع المخالفات حسب الخطورة والنوع.
   - كشف الطلاب ذوي السلوك الحرج (النقاط >= 10).
   - مؤشر المزامنة السحابية الحية وحالة الاتصال.

2. **سجل الطلاب الشامل (722 طالب)**:
   - بحث فوري بالاسم أو الرقم المدرسي.
   - فلترة حسب الصف الدراسي (السابع، الثامن، التاسع، العاشر) والشعبة (1-5).
   - عرض ملف الطالب السلوكي الشامل والتاريخ الزمني لجميع مخالفاته.

3. **تسجيل المخالفات السلوكية التراكمية**:
   - اختيار المخالفة من مدونة السلوك الرسمية (20 نوع مخالفة مع النقاط المحددة ودرجة الخطورة).
   - تحديد المعلم المسجل من الكشف الرسمي (31 معلماً).
   - اختيار التاريخ والوقت بدقة حسب التوقيت المحلي للمملكة الأردنية الهاشمية.
   - إضافة ملاحظات وتفاصيل إضافية لكل مخالفة.

4. **المزامنة السحابية اللحظية (Google Firebase Firestore)**:
   - مزامنة فورية Real-time بين جميع هواتف المعلمين وأجهزة الكمبيوتر.
   - إشعار تنبيهي صوتي ومرئي فور تسجيل أي مخالفة من أي جهاز.
   - حفظ تلقائي غير متصل بالإنترنت في التخزين المحلي للمتصفح (Offline Cache) والمزامنة التلقائية عند عودة الاتصال.

5. **إصدار الوثائق الرسمية للطباعة والتصدير**:
   - إنذار سلوكي رسمي.
   - تعهد خطي للطالب وولي الأمر.
   - استدعاء ولي أمر.
   - كشف وتقرير متابعة سلوكية شامل.
   - إمكانية التصدير إلى صيغة Word (.doc)، أو HTML، أو نسخ النص مباشرة مع التواقيع الرسمية لمدير المدرسة والمرشد وولي الأمر وختم المدرسة.

6. **التقارير والإحصائيات وتصدير البيانات**:
   - تقارير شهرية وفصلية وسنوية لجميع المخالفات.
   - تصدير كشوفات المخالفات إلى ملفات Excel/CSV مع دعم كامل للغة العربية UTF-8 BOM.
   - تصدير واستيراد نسخ احتياطية كاملة بصيغة JSON.

7. **إدارة كشف المعلمين**:
   - كشف المعلمين الرسمي (31 معلماً) مع الأرقام الوظيفية والمسميات.
   - إمكانية إضافة معلم جديد أو تعديل بيانات معلم أو حذفه مع انعكاس سحابي دائم.
